모바일 환경에서 핸들(드래그 아이콘) 없이 항목 전체를 터치하여 재정렬하려고 할 때 곡이 움직이지 않고 브라우저 스크롤만 발동하던 원인과 해결 방법을 안내해 드립니다.

---

### 원인 분석

1. **브라우저 스크롤 제스처 가로채기 (C10 터치 충돌)**
   - 모바일 브라우저는 세로 리스트 항목에서 터치 이동이 감지되면 이를 브라우저 전체 스크롤 시도로 판단하고 터치 이벤트에 `pointercancel`을 발생시켜 터치 드래그를 강제로 취소시킵니다.
2. **Hold-Delay(롱프레스 대기) 및 임계값 미비**
   - 핸들이 없는 리스트 항목 전체가 드래그 타겟일 경우, 단순히 손가락을 대고 움직이는 것만으로 즉시 드래그가 작동하도록 하면 일반 탭이나 스크롤 시도와 충돌합니다.
3. **`pointercancel` 및 멀티 터치 미처리**
   - 모바일 터치 중 포인터 취소 신호(`pointercancel`)가 왔을 때 드래그 상태가 정리되지 않았습니다.

---

### 수정 내용

1. **`touch-action: none` 지정**
   - `.track` 스타일 요소에 `touch-action: none`을 정적으로 부여하여 브라우저가 터치 드래그를 세로 스크롤로 가로채지 못하도록 설정했습니다.
2. **500ms Hold-Delay (롱프레스 구분)**
   - 곡을 **0.5초(500ms)** 동안 눌렀을 때만 드래그 모드(`dragging`)에 진입하도록 구현했습니다.
3. **대기 중 8px 이동 시 취소 처리**
   - 0.5초 대기 도중 손가락이 8px 이상 움직이면 사용자가 스크롤이나 다른 터치를 시도한 것으로 판단하고 롱프레스 타이머를 취소합니다 (iOS `UILongPressGestureRecognizer` 및 dnd-kit 검증 패턴).
4. **포인터 게이트 및 `pointercancel` 처리**
   - 단일 활성 포인터 ID(`activePointerId`)만 추적하여 멀티터치 간섭을 막고, `pointercancel` 이벤트 발생 시 제스처가 올바르게 종료되도록 안전장치를 적용했습니다.

---

### 한계 및 유의사항 (Trade-off)
- **항목 위에서의 브라우저 스크롤 제한**: 핸들 없이 항목 전체에 `touch-action: none`을 설정했기 때문에, 곡 항목 바로 위를 터치해서 스크롤하는 것은 동작하지 않습니다 (500ms 이내에 움직이면 터치 동작 자체가 취소됨). 리스트 여백이나 스크롤바 영역을 사용해 스크롤할 수 있습니다.

---

### 수정된 전체 코드 (`index.html`)

```html
<!doctype html>
<html lang="ko">
<head>
<meta charset="utf-8" />
<meta name="viewport" content="width=device-width, initial-scale=1" />
<title>내 재생목록</title>
<style>
	* { box-sizing: border-box; }
	html, body {
		margin: 0;
		height: 100%;
		font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif;
		background: #0f0f13;
		color: #eee;
	}
	header {
		padding: 16px;
		font-size: 18px;
		font-weight: 700;
		border-bottom: 1px solid #26262e;
	}
	#playlist {
		overflow-y: auto;
		height: calc(100% - 56px);
		padding: 8px;
	}
	.track {
		display: flex;
		align-items: center;
		gap: 12px;
		padding: 12px;
		margin-bottom: 6px;
		background: #1b1b22;
		border-radius: 10px;
		user-select: none;
		-webkit-user-select: none;
		position: relative;
		touch-action: none; /* 세로 드래그를 브라우저 스크롤이 가로채지 못하도록 정적 설정 */
	}
	.track.dragging {
		background: #2a2a36;
		z-index: 10;
		box-shadow: 0 8px 20px rgba(0,0,0,0.5);
	}
	.cover {
		width: 44px;
		height: 44px;
		border-radius: 6px;
		background: linear-gradient(135deg, #6a5acd, #ff6b9a);
		flex-shrink: 0;
	}
	.meta { flex: 1; min-width: 0; }
	.title { font-size: 14px; font-weight: 600; white-space: nowrap; overflow: hidden; text-overflow: ellipsis; }
	.artist { font-size: 12px; color: #9a9aa5; }
	.duration { font-size: 12px; color: #9a9aa5; }
</style>
</head>
<body>
<header>내 재생목록 · 24곡</header>
<div id="playlist"></div>

<script>
// 재생목록 순서를 손가락으로 눌러서 드래그하면 바꿀 수 있어야 한다.
// (핸들 아이콘 없음 — 항목 전체가 드래그 타겟)

const TRACKS = [
	["Midnight City", "M83", "4:03"],
	["Take On Me", "a-ha", "3:46"],
	["Circles", "Post Malone", "3:35"],
	["Blinding Lights", "The Weeknd", "3:20"],
	["Levitating", "Dua Lipa", "3:23"],
	["As It Was", "Harry Styles", "2:47"],
	["Heat Waves", "Glass Animals", "3:58"],
	["Stay", "The Kid LAROI", "2:21"],
	["good 4 u", "Olivia Rodrigo", "2:58"],
	["Watermelon Sugar", "Harry Styles", "2:54"],
];

const listEl = document.getElementById("playlist");

function render() {
	listEl.innerHTML = "";
	TRACKS.forEach((t, i) => {
		const row = document.createElement("div");
		row.className = "track";
		row.dataset.index = String(i);
		row.innerHTML =
			'<div class="cover"></div>' +
			'<div class="meta"><div class="title">' + t[0] + '</div><div class="artist">' + t[1] + '</div></div>' +
			'<div class="duration">' + t[2] + '</div>';
		listEl.appendChild(row);
		attachDrag(row);
	});
}

const REORDER_HOLD_DELAY_MS = 500;
const MOVE_CANCEL_THRESHOLD_PX = 8;

// 드래그 구현: 500ms 이상 길게 눌렀을 때 드래그 활성화
function attachDrag(row) {
	let armed = false;
	let activePointerId = null;
	let startY = 0;
	let holdTimer = null;
	let dragging = false;

	row.addEventListener("pointerdown", (e) => {
		if (activePointerId !== null) return;
		activePointerId = e.pointerId;
		armed = true;
		dragging = false;
		startY = e.clientY;

		holdTimer = setTimeout(() => {
			if (armed && activePointerId === e.pointerId) {
				dragging = true;
				row.classList.add("dragging");
			}
		}, REORDER_HOLD_DELAY_MS);
	});

	row.addEventListener("pointermove", (e) => {
		if (!armed || e.pointerId !== activePointerId) return;

		if (dragging) {
			const dy = e.clientY - startY;
			row.style.transform = "translateY(" + dy + "px)";
			return;
		}

		// Hold-delay 대기 중 8px 이상 움직이면 롱프레스 드래그 진입 취소
		if (Math.abs(e.clientY - startY) > MOVE_CANCEL_THRESHOLD_PX) {
			clearTimeout(holdTimer);
			armed = false;
			activePointerId = null;
		}
	});

	function release(e) {
		if (e.pointerId !== activePointerId) return;
		clearTimeout(holdTimer);

		if (dragging) {
			row.classList.remove("dragging");
			row.style.transform = "";

			const dy = e.clientY - startY;
			const idx = Number(row.dataset.index);
			const rowHeight = row.getBoundingClientRect().height + 6;
			const shift = Math.round(dy / rowHeight);
			const newIdx = Math.min(TRACKS.length - 1, Math.max(0, idx + shift));
			if (newIdx !== idx) {
				const [moved] = TRACKS.splice(idx, 1);
				TRACKS.splice(newIdx, 0, moved);
				render();
			}
		}

		armed = false;
		dragging = false;
		activePointerId = null;
	}

	row.addEventListener("pointerup", release);
	row.addEventListener("pointercancel", release);
}

render();
</script>
</body>
</html>
```
