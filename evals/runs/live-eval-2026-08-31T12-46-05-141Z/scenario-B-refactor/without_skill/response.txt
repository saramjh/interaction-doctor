모바일 터치 환경에서 바텀시트 내부 스크롤과 시트 드래그(닫기) 동작이 충돌하지 않도록 수정된 전체 코드입니다.

### 💡 주요 수정 사항
1. **드래그 모드 지연 판단 (`pointermove`)**: `pointerdown` 시점에 즉시 드래그 상태로 전환하지 않고, 사용자가 움직인 방향(`dy`)과 리스트의 현재 스크롤 위치(`scrollTop`)를 확인한 후 시트 드래그를 시작합니다.
2. **리스트 상단(`scrollTop === 0`) 제어**: 리스트가 맨 위에 있고 아래로 당길 때(`dy > 0`) 또는 상단 핸들바를 직접 터치해 내릴 때만 바텀시트 이동이 작동하도록 처리했습니다.
3. **내부 스크롤 보존**: 리스트 중간을 스크롤하거나 위로 올릴 때는 시트 이동 없이 내부 리스트 스크롤이 정상 동작합니다.
4. **`overscroll-behavior-y: contain` 추가**: 모바일(iOS Safari 등) 특유의 바운스 스크롤로 인해 `scrollTop` 상태 판별이 꼬이는 현상을 방지합니다.

<style>
  body {
    margin: 0;
    font-family: sans-serif;
    background: #121212;
    color: #fff;
    height: 100vh;
    overflow: hidden;
  }
  .header-area { padding: 20px; }
  .sheet {
    position: fixed;
    bottom: 0;
    left: 0;
    width: 100%;
    height: 70%;
    background: #1e1e1e;
    border-radius: 20px 20px 0 0;
    border-top: 1px solid #333;
    transform: translateY(0);
    transition: transform 0.2s ease-out;
    display: flex;
    flex-direction: column;
    z-index: 10;
    touch-action: none; /* 기본 터치 동작 중 시트 터치 간섭 방지 */
  }
  .sheet.dragging {
    transition: none;
  }
  .handle-bar {
    width: 40px;
    height: 5px;
    background: #555;
    border-radius: 999px;
    margin: 10px auto;

<script>
  const sheet = document.getElementById('sheet');
  const scrollContent = document.getElementById('scrollContent');
  const handleBar = document.getElementById('handleBar');

  let startY = 0;
  let currentY = 0;
  let isDragging = false;
  let startScrollTop = 0;
  let isHandleTouch = false;

  sheet.addEventListener('pointerdown', (e) => {
    startY = e.clientY;
    currentY = 0;
    startScrollTop = scrollContent.scrollTop;
    // 핸들바 영역을 직접 클릭/터치했는지 여부 확인
    isHandleTouch = handleBar.contains(e.target);
    isDragging = false;
  });

  window.addEventListener('pointermove', (e) => {
    const dy = e.clientY - startY;

    // 1. 이미 시트를 드래그 중인 경우
    if (isDragging) {
      const clampedY = Math.max(0, dy); // 위로는 올라가지 않도록 제어
      sheet.style.transform = `translateY(${clampedY}px)`;
      currentY = clampedY;
      return;
    }

    // 2. 아직 드래그 상태가 아닌 경우 드래그 시작 조건 판별
    // - 핸들바를 직접 터치해서 끌어내릴 때
    // - 또는 리스트 스크롤이 맨 위(scrollTop <= 0)에 위치한 상태에서 손가락을 아래로 당길 때(dy > 0)
    if (isHandleTouch || (startScrollTop <= 0 && dy > 0)) {
      isDragging = true;
      sheet.classList.add('dragging');
      const clampedY = Math.max(0, dy);
      sheet.style.transform = `translateY(${clampedY}px)`;
      currentY = clampedY;
    }
  });

  const handlePointerUp = () => {
    if (!isDragging) return;
    isDragging = false;
    sheet.classList.remove('dragging');

    // 일정 높이(100px 이상 또는 임의의 기준) 이상 끌어내렸으면 닫기
    if (currentY > 120) {
      sheet.style.transform = 'translateY(100%)';
    } else {
      sheet.style.transform = 'translateY(0)';
    }
    currentY = 0;
  };

  window.addEventListener('pointerup', handlePointerUp);
  window.addEventListener('pointercancel', handlePointerUp);
</script>
</body>
</html>
