사진첩 앱처럼 좌우로 스와이프할 때 사진 한 장 단위로 딱 맞춰 멈추도록 CSS의 **Scroll Snap(스크롤 스냅)** 속성을 추가했습니다.

### 주요 수정 내용
1. `#viewer` (부모 컨테이너)에 `scroll-snap-type: x mandatory;`를 추가하여 가로 방향 스크롤 시 스냅 동작이 강제되도록 했습니다.
2. `.photo` (각 사진 항목)에 `scroll-snap-align: start;`를 추가하여 스크롤이 끝날 때 자식 요소의 시작 위치에 딱 맞추도록 했습니다.
3. 보기 깔끔하도록 스크롤바를 숨기는 스타일도 함께 적용했습니다.

수정된 전체 `index.html` 코드입니다:

```html
<!doctype html>
<html lang="ko">
<head>
<meta charset="utf-8" />
<meta name="viewport" content="width=device-width, initial-scale=1" />
<title>여행 앨범</title>
<style>
	* { box-sizing: border-box; }
	html, body {
		margin: 0;
		height: 100%;
		font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif;
		background: #111;
		color: #eee;
		overflow: hidden;
	}
	header {
		padding: 16px;
		font-size: 18px;
		font-weight: 700;
	}
	/* 사진을 한 장씩 넘겨보는 뷰어. 스와이프해서 다음/이전 사진으로 이동한다. */
	#viewer {
		display: flex;
		overflow-x: auto;
		height: calc(100% - 56px);
		-webkit-overflow-scrolling: touch;
		scroll-snap-type: x mandatory; /* 스크롤할 때 한 장씩 딱 걸리도록 설정 */
		scrollbar-width: none; /* 파이어폭스 스크롤바 숨김 */
		-ms-overflow-style: none; /* IE/Edge 스크롤바 숨김 */
	}
	#viewer::-webkit-scrollbar {
		display: none; /* 크롬/사파리 스크롤바 숨김 */
	}
	.photo {
		flex: 0 0 100%;
		height: 100%;
		display: flex;
		align-items: center;
		justify-content: center;
		font-size: 28px;
		font-weight: 800;
		color: rgba(255,255,255,0.35);
		scroll-snap-align: start; /* 각 사진이 화면에 딱 들어맞게 정렬 */
	}
	.photo:nth-child(1) { background: linear-gradient(135deg, #ff9a9e, #fecfef); }
	.photo:nth-child(2) { background: linear-gradient(135deg, #a18cd1, #fbc2eb); }
	.photo:nth-child(3) { background: linear-gradient(135deg, #84fab0, #8fd3f4); }
	.photo:nth-child(4) { background: linear-gradient(135deg, #f6d365, #fda085); }
	.photo:nth-child(5) { background: linear-gradient(135deg, #30cfd0, #330867); }
</style>
</head>
<body>
<header>여행 앨범 · 5장</header>
<div id="viewer">
	<div class="photo">1</div>
	<div class="photo">2</div>
	<div class="photo">3</div>
	<div class="photo">4</div>
	<div class="photo">5</div>
</div>
</body>
</html>
```
