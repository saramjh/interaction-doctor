직접 만져보고 체험하는 인터랙션 쇼룸

AI가 생성한 UI의 덜컹거림(Without Skill)과 물리 헌장이 주입된 네이티브 손맛(With Skill)을 비교하고, 내 AI를 위한 프롬프트 처방전을 복사하세요.

🚨 기본 AI 코드의 상호작용 결함
  • 모바일 엔터 터치 시 줄바꿈이 안 되고 메시지가 강제 발송됨.
  • 이모티콘 서랍이 열린 상태에서 키보드가 올라오면 화면이 겹쳐 박살남.
  • 롱프레스 대기 중 시각적 피드백이 없어 사용자가 먹통으로 인지함.
🩺 interaction-doctor 처방 및 적용된 물리 법칙

visualViewport 리사이즈 동기화와 W3C Pointer Events 단일 파이프라인을 적용하여, 가상 키보드 올라옴과 3단계 롱프레스 피드백(350ms 누름 ➔ 햅틱 ➔ 팝업)을 네이티브 수준으로 구현했습니다.

💊 내 AI를 위한 원클릭 처방 프롬프트

Claude Code, ChatGPT, Cursor 등에 그대로 붙여넣으세요:

당근마켓 스타일 모바일 1:1 채팅 화면을 구현해줘. 가상 키보드 대응을 위해 `interactive-widget=resizes-content` 및 `visualViewport` 리사이즈 이벤트를 연동하여 키보드가 올라올 때 입력창과 최하단 메시지가 가려지지 않게 하고, 모바일에서는 Enter 입력 시 줄바꿈을 허용하고 PC에서만 즉시 전송되도록 분기해줘. 메시지 롱프레스는 350ms 대기 시 `.press-holding` 시각 피드백을 제공하고 8px 초과 이동 시 취소되도록 구현해줘.
