📐 16대 핵심 물리 불변식 헌장 (Core Invariants)

AI 에이전트가 코드를 작성할 때 엄격하게 준수하도록 강제하는 하드웨어 실측 물리 법칙입니다:

⏱️ 350ms Temporal Gate

의도적인 드래그/롱프레스와 고속 스크롤을 분리하여 스크롤 중 카드가 덜컥 잡히는 결함을 차단합니다.

📏 8.0px Slop Hysteresis

8px 이하의 미세 손떨림을 흡수하여 플로팅 버튼(FAB) 드래그 후 놓았을 때의 오클릭 발화를 방지합니다.

📱 0ms VisualViewport Sync

망가진 100vh 대신 VisualViewport API를 구독하여 가상 키보드 높이만큼 입력창을 0ms GPU 리프트합니다.

🎯 Centroid Invariant (Zoom)

핀치 줌 시 손가락 사이 중심점(Centroid)을 0.000px 오차로 고정하여 확대 시 타겟 핀 이탈을 방지합니다.

🔒 W3C setPointerCapture

비디오 스크러버나 컬럼 리사이즈 시 손가락이 트랙 밖으로 빗나가도 끊김 없이 연속 추종합니다.

🛡️ 20px OS Edge Deadzone

화면 가장자리 20px 영역의 스와이프를 무시하여 OS 뒤로가기 제스처와의 충돌을 원천 방어합니다.
