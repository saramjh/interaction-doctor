    How to Install & Use interaction-doctor

    Never write manual gesture math again. Inject 16-device hardware touch physics into your AI coding assistant in 3 simple steps.

    1
    For Claude Code / Antigravity

    Open your terminal in your project root directory and run the official universal installer:

    npx skills add saramjh/interaction-doctor

    💡 Select your agent (Claude Code / Antigravity), press Enter, and you are ready!

    2
    For ChatGPT / Claude Web / Gemini

    No terminal or CLI required! Copy the complete lossless standalone physics prompt:

    STANDALONE.md (Prompt)

    💡 Paste this directly into Custom GPTs instructions or your first chat prompt.

    3
    Zero-Config Automatic Execution

    Once installed, you don't need to learn complex physics formulas. Just ask your AI normally:

    "Create a mobile chat with long-press context menu and bottom sheet."

    ✨ The AI automatically loads the skill and generates bug-free touch code with 8px axis lock & 0ms viewport sync!

    ✅ How to Verify That Your AI is Using the Skill

    • Check for 8px Axis Lock: Look for Math.hypot(dx, dy) > 8 in your AI's touch event handlers.
    • Check for VisualViewport: Look for window.visualViewport.addEventListener('resize') in mobile input code.
    • Check for Pointer Events: Look for unified pointerdown / pointermove instead of fragmented HTML5 drag code.
