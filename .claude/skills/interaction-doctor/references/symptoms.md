# 상호작용 결함 증상 역추적 진단서 (Interaction Diagnostics)

## 0. 개요: 체감 증상으로부터 원인을 역추적하는 나침반

사용자가 소프트웨어를 쓰다가 "조작감이 불쾌하다"고 느낄 때, 개발자는 무엇이 잘못되었는지 즉시 진단할 수 있어야 한다.
본 문서는 **사용자가 겪는 체감 증상(Symptoms)으로부터 근본 원인(Root Cause)과 해결 불변식을 즉시 역추적**하는 룩업 가이드이다.

---

## 1. 5대 클러스터 & 7대 런타임 찐빠 역추적 진단표

| 체감 증상 (User Pain Point) | 분류 | 근본 기술적 원인 (Root Cause) | 해결 불변식 & 프로토콜 |
|:---|:---:|:---|:---|
| **"슬라이더를 넘기는데 본문이 위아래로 덜컹거려요"** | **C1** | 초기 터치 시 8px 축 잠금(Axis Lock) 누락으로 수직 스크롤러가 동시 개입함 | 초기 8px 이동 후 주 이동 방향으로 축 잠금, 직교 축 스크롤러 차단 |
| **"손가락을 휙 던졌는데 스크롤이 0.1초 만에 뚝 멈춰요"** | **C1** | 릴리즈 순간 단일 프레임 속도(`dx/dt`)만 읽어 손가락 멈춤 구간에서 속도가 0이 됨 | 최근 100~120ms 동안의 이동 궤적 큐(Queue) 평균 속도 벡터로 관성 감속 |
| **"스크롤 도중 다시 화면을 잡았는데 갑자기 튕겨나가요"** | **C1** | 새 터치 진입 시 기존 `requestAnimationFrame` 루프를 취소하지 않아 관성 루프 중첩 가속 | 새 터치(`pointerdown`) 즉시 실행 중인 모든 애니메이션 루프 취소(`cancel`) |
| **"뷰가 렌더링되자마자 스크롤했더니 화면이 하얗게 뻗어요"** | **C1** | 가로폭 계산 전 0 나누기로 인해 `delta / 0 = Infinity` 및 $NaN$ 발생 | 모든 나눗셈 연산의 분모에 `Math.max(1, width)` 안전 가드 적용 |
| **"두 손가락으로 줌을 당기는데 화면이 멈추거나 튕겨요"** | **C2** | 유클리드 거리 수식에서 인덱스 참조 오타(`pts[1]` 누락)로 거리 값이 $NaN$이 됨 | 다점 연산 시 서로 다른 식별자(Disjoint ID) 매칭 심볼릭 트레이스 |
| **"두 손가락 중 하나를 떼는 순간 화면이 팍 튀어요"** | **C2** | 포인터 수 변경($N \to 1$) 시 남은 손가락의 위치로 원점을 갱신하지 않아 델타 폭발 | 포인터 수 증감 즉시 남은 포인터 위치를 새 시작 앵커로 실시간 재동기화 |
| **"카드를 꾹 눌러서 옮기려는데 자꾸 취소돼요"** | **C3** | 손가락의 1~2px 미세한 생리적 손떨림을 '이동'으로 오판하여 롱프레스 타이머를 파기함 | 5~8px 터치 슬롭(Slop) 이내의 움직임은 타이머 누적을 유지 |
| **"손을 뗐는데 뒤늦게 롱프레스 팝업이 튀어나와요"** | **C3** | 릴리즈/취소 시점에 `clearTimeout`을 누락하여 백그라운드 타이머가 유령 발화 | `pointerup`, `pointercancel`, 슬롭 초과 등 모든 이탈 경로에서 타이머 즉시 폐기 |
| **"바텀시트를 끌 수 있게 했더니 내부 닫기 버튼이 안 눌려요"** | **C3** | 부모 컨테이너가 터치 시작 즉시 `setPointerCapture`를 독점하여 자식의 클릭을 가로챔 | 8px 슬롭 이동이 발생하기 전까지는 자식의 단일 탭 권한을 보존 |
| **"버튼을 눌렀는데 반응이 반 박자 굼떠요"** | **C3** | 브라우저/시스템의 더블탭 줌 대기 타이머(300ms)가 싱글탭 발화를 가로막음 | 더블탭이 불필요한 영역은 0ms 즉시 실행, 필요한 영역만 독립 큐로 분기 |
| **"키보드가 올라오니까 내가 뭘 타이핑하는지 안 보여요"** | **C4** | 가상 키보드 팝업으로 가용 높이가 줄었는데 활성 인풋이 뷰포트 밖으로 밀려남 | `VisualViewport` API 구독 및 활성 포커스 필드 자동 안전 영역 스크롤 |
| **"아이폰 하단 홈바에 버튼이 겹쳐서 안 눌려요"** | **C4** | 기기 고유의 Safe-Area Inset(하단 34pt) 마진을 확보하지 않음 | `env(safe-area-inset-bottom)`을 명시하여 시스템 바와 UI 물리적 분리 |
| **"버튼을 눌렀는데 눌렸는지 안 눌렸는지 모르겠어요"** | **C5** | 터치 시작 시점의 0ms 즉각 시각/촉각 피드백(눌림 스케일, 햅틱) 누락 | 터치 시작 즉시 $0\text{ms}$ 스케일 압축(0.96) 및 햅틱 클릭 발화 |
| **"팝업을 닫았더니 그 뒤에 있던 버튼이 같이 눌려요"** | **C5** | 300ms 뒤 발사되는 합성 마우스 클릭이 닫힌 팝업 뒷자리로 관통함 | 터치 액션 완료 시 `e.preventDefault()`로 후속 합성 클릭 생성 차단 |
| **"결제/저장 버튼을 두 번 눌렀더니 중복 처리됐어요"** | **C5** | 비동기 네트워크 요청 진행 중 버튼에 멱등성 비활성화(Disable Lock)가 걸리지 않음 | 첫 터치 릴리즈 즉시 버튼 락(Debounce)을 걸어 중복 이벤트 원천 차단 |
