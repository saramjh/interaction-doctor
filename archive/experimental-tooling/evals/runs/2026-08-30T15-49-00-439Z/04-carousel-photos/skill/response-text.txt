### 진단 및 수정 안내

* **확신도 라벨**: **[표준]** (W3C CSS Scroll Snap 스펙, iOS/Android 네이티브 캐러셀 스냅 스펙)
* **원인**: `#viewer` 영역에 자유 스크롤(`overflow-x: auto`)만 적용되어 있고, 스크롤 정지 지점을 강제하는 스냅(Snap) 설정이 누락되어 있어서 일어나는 현상입니다.
* **해결 방법**: 
  1. 부모 컨테이너(`#viewer`)에 `scroll-snap-type: x mandatory;`를 부여하여 가로 스크롤 시 반드시 특정 사진에 스냅되도록 합니다.
  2. 각 사진 아이템(`.photo`)에 `scroll-snap-align: start;`를 적용해 화면 좌측 시작점에 사진이 딱 맞아떨어지게 합니다.
  3. 한 번에 여러 장이 빠르게 지나가지 않고 사진첩 앱처럼 한 장씩 멈추도록 `scroll-snap-stop: always;`를 추가합니다.

---

```html
		margin: 0;
		height: 100%;
		font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif;
		background: #111;
		color: #eee;
		overflow: hidden;
	}
	header {
		padding: 16px;
		font-size: 18px;
		font-weight: 700;
	}
	/* 사진을 한 장씩 넘겨보는 뷰어. 스와이프해서 다음/이전 사진으로 이동한다. */
	#viewer {
		display: flex;
		overflow-x: auto;
		height: calc(100% - 56px);
		-webkit-overflow-scrolling: touch;
		scroll-snap-type: x mandatory;
	}
	.photo {
		flex: 0 0 100%;
		height: 100%;
		display: flex;
		align-items: center;
		justify-content: center;
		font-size: 28px;
		font-weight: 800;
		color: rgba(255,255,255,0.35);
		scroll-snap-align: start;
		scroll-snap-stop: always;
	}
	.photo:nth-child(1) { background: linear-gradient(135deg, #ff9a9e, #fecfef); }
	.photo:nth-child(2) { background: linear-gradient(135deg, #a18cd1, #fbc2eb); }

	.photo:nth-child(5) { background: linear-gradient(135deg, #30cfd0, #330867); }
</style>
</head>
<body>
<header>여행 앨범 · 5장</header>
<div id="viewer">
	<div class="photo">1</div>
	<div class="photo">2</div>
	<div class="photo">3</div>
	<div class="photo">4</div>
	<div class="photo">5</div>
</div>
</body>
</html>
```
